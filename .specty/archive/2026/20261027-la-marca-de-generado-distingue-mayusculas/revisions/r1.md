# La marca de generado distingue mayúsculas

## Objetivo

La marca de generado de las primeras 10 líneas no distingue mayúsculas, así que la prosa de un comentario («and generated code», «the code generated by», «do not edit») hace pasar por generado un archivo escrito a mano: no cuenta para el tamaño, se salta la regla `lines` y `specty check`, y su alcance se aprueba solo con `tests-and-generated`. En este repositorio les pasa a `check/install-ignores.ts` y a `test/check-ignores.test.ts`, que el último cambio midió como «0 archivos». Las marcas pasan a distinguir mayúsculas como las escriben las herramientas (`DO NOT EDIT`, `GENERATED CODE`, `Code generated`), con variantes explícitas para las que aparecen en otra forma (`@generated` y `@Generated`, `Do not edit`, `auto-generated` y `Auto-generated`, `<auto-generated>`); las que ya detectan los tests siguen detectándose.

## Archivos
